# External Agent Skills

Vendored copies of third-party Agent Skills. **Do not hand-edit the contents of `.agents/skills/<folder>-<name>/`** - changes are overwritten on the next `copier update`. To adjust a skill, propose the change upstream or fork it into your own skills tree under a different name.

To change what's vendored, edit the `external_skills` answer and run:
`copier update --trust --answers-file .copier-answers.agent-instructions.yml`
